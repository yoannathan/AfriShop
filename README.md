# AfriShop

AfriShop est un site vitrine consacré à la découverte et à la vente de produits africains : vêtements, artisanat et café local.

## Auteur

Yoan

## Technologies

- HTML5 sémantique
- CSS3 et Flexbox
- Git et GitHub

## Lancement

1. Ouvrir le dossier `AfriShop` dans Visual Studio Code.
2. Ouvrir `index.html` dans un navigateur, ou utiliser l’extension Live Server.
3. Naviguer entre les sections Accueil, Produits et Contact.

## Historique des versions

- `v1.0.0` : structure, navigation et accueil
- `v1.1.0` : catalogue, contact et pied de page
